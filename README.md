# Bank Management System
<img width="1536" height="1024" alt="Neon C++ Bank Management System Poster-2" src="https://github.com/user-attachments/assets/5b84e9b5-427a-4c30-b4a5-8f2096086235" />


Console-based banking system built as an educational project using C++ and OOP principles.

## Features

* Role-based login, permissions system, and Login activity logs.
* Full CRUD operations for clients and system users.
* Transaction handling (deposit, withdraw, transfers, transfer logs).
* Currency exchange (list currencies, find currency, update rates, and currency calculator).

## Getting Started & First-Time Setup

To build and run the system locally, follow these steps:

### Prerequisites
* Windows OS
* Visual Studio (with C++ Desktop Development workload)

### Quick Start
1. Clone the repository:
   ```bash
   git clone https://github.com/Mostafa-1-Abdo/bank-system.git
2. Open bank-system.slnx (or bank-system.vcxproj) in Visual Studio.
3. Database / Credentials Setup:
   * Rename Users.txt.template to Users.txt in the project root directory.
4. Build and Run the project (Ctrl + F5).
